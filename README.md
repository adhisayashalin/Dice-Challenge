# Dicee Game 🎲

## About the Project

Dicee is a simple two-player dice game made using HTML, CSS and JavaScript.

When we click the **Refresh button**, both dice roll and show a random number between 1 and 6. The game then checks the numbers and shows who won.

## How It Works

* Click the **Refresh button** to roll the dice.
* Player 1 gets a random dice number.
* Player 2 gets a random dice number.
* The dice images change according to the numbers.
* If Player 1 gets a higher number, Player 1 wins.
* If Player 2 gets a higher number, Player 2 wins.
* If both get the same number, it shows **Draw**.

## How to Run

1. Open the `index.html` file in a browser.
2. Click the **Refresh button**.
3. The dice will roll and the winner will be displayed.
4. Click Refresh again to play another round.
